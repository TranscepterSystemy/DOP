# Публичные решения

ДОП — Детские Обучающие Программы, проект «Трансцептер системы». Принцип: «Не решаем за тебя. Учим понимать». Единый публичный репозиторий, отдельные релизы каждой программы. Исходный код по умолчанию закрыт. Минимизировать сбор данных, не включать рекламу и внешние сервисы без отдельного решения и оценки безопасности детей.
