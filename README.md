## Наши программы

### 🧩 Дроби

Приложение для знакомства с дробями и практики работы с ними.

**Для кого:** для школьников, которые изучают дроби, и родителей, помогающих им заниматься.

**Статус:** эталонная APK-сборка сохранена; публичная загрузка готовится.

### ➗ Деление в столбик

Приложение для практики деления в столбик — одного из важных навыков школьной математики.

**Для кого:** для школьников, осваивающих письменное деление, и родителей.

**Статус:** эталонная APK-сборка сохранена; публичная загрузка готовится.

## 📥 Как скачать

Когда проверенные сборки будут опубликованы, они появятся в разделе **[Releases](https://github.com/TranscepterSystemy/DOP/releases)**.

Планируем размещать APK-файлы для Android. Пока раздел может быть пустым — не скачивайте случайные файлы из сторонних источников от имени проекта.

## 📱 Установка на Android

1. Откройте опубликованный релиз и скачайте APK нужной программы.
2. Запустите скачанный файл на устройстве Android.
3. Если система попросит разрешение на установку из выбранного источника, внимательно проверьте источник файла и следуйте подсказкам Android.
4. После установки откройте приложение.

> Совместимость с конкретными версиями Android и устройствами будет указана после отдельной проверки.

## 💡 Зачем существует ДОП?

Мы хотим, чтобы полезные учебные инструменты были простыми и понятными. Без сложной регистрации и длинных инструкций: выбрал нужную тему, открыл приложение и занимаешься.

ДОП расшифровывается как **Детские Обучающие Программы**.

## 🔎 Состояние проекта

Проект находится на этапе подготовки публичной страницы и дистрибутивов. Две эталонные сборки используются автором, но их совместимость с другими устройствами ещё не подтверждена.

Исходный код пока не опубликован. Наличие публичного репозитория не означает, что программное обеспечение распространяется по открытой лицензии.
